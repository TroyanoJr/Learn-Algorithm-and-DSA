# Linear Search Complexity

Linear search performance depends on the position of the target element in the list.

## Time Complexity Summary

- **Best Case**: O(1) when target is at index 0.
- **Worst Case**: O(n) when target is at the end or not present.
- **Average Case**: O(n) comparisons.

It requires no pre-sorting and works on unsorted arrays as well as linked lists.

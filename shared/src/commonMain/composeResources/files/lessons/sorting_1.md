# What Is Sorting?

Sorting is the process of arranging data elements into a specific logical order, typically ascending or descending.

Imagine sorting playing cards in your hand or organizing files alphabetically. In computer science, sorted data dramatically improves search speeds and data analysis efficiency.

## Key Concepts

- **Ascending Order**: Arranging elements from smallest to largest (`[1, 2, 4, 5, 8]`).
- **Descending Order**: Arranging elements from largest to smallest (`[8, 5, 4, 2, 1]`).
- **In-Place Sorting**: Reordering elements directly within the original array without extra memory.

### Code Example

```kotlin
val unsorted = intArrayOf(5, 2, 8, 1, 4)
val sorted = unsorted.sortedArray() // [1, 2, 4, 5, 8]
```

## Summary

Sorting transforms raw unstructured data into an ordered sequence, enabling efficient search algorithms like Binary Search.
